第一次上岛，先把家安下来 ​

别急着把整座岛铺满机器，先想想第一批资源从哪里来。这份指南帮你找到岛屿面板、任务和资源入口，方便开始自己的建设计划。

还没有进入科技空岛？

这里需要匹配的 Java 1.21.1 模组客户端。整合包下载与连接方式仍待补充，先看 加入说明，不要拿增强生存的客户端下载入口代替。

1. 创建或管理自己的岛屿 ​

在聊天栏输入：

text
/is

根据当前菜单创建或管理岛屿；如果准备和朋友同住，可以先商量由谁建岛，再按服内界面加入。可用模板与权限以实际菜单为准。

想回到自己的岛屿：

text
/is tp

2. 打开岛屿管理面板 ​

text
/is panel

先熟悉返回岛屿、成员、权限、任务和升级等入口。多人合作时，先确认每个人的权限和分工，再开始集中存放资源或改动设备。

3. 在任务里找一个起步目标 ​

从管理面板进入任务，也可以输入：

text
/is missions

看看当前能完成的矿工、农夫、渔夫等任务，先读目标，再读奖励。部分奖励与生成器成长、漂流鱼竿升级芯片有关，具体要求以游戏内任务为准。

不必把任务当作必须照走的科技顺序，也不要默认所有机器产出都会计入任务统计。更多说明见 岛屿成长与资源生产。

4. 认识漂流鱼竿，找基础材料与种源 ​

使用专用漂流鱼竿在空旷位置向空气抛竿，等待咬钩后收竿，可以从该等级奖池获得材料。普通鱼竿或只改了名字的鱼竿不能替代它。

初始漂流鱼竿的具体获取方式仍待服主确认。 请先查看当前服内引导或向管理员询问，不要尝试网上的管理员发放命令。

  • 漂流钓鱼指南：抛竿方式、等级区别与常见问题。
  • 六级完整奖池：缺什么材料，先查哪一根竿能钓到。
  • XPlus 参考设置：已经在使用对应辅助功能时，可按教程尝试。

5. 看看生成器，以及全岛共用的额度 ​

通过面板查看岛屿升级，或输入：

text
/is upgrade

矿物生成器的产出随等级变化，同时受岛屿共享的矿物生成额度影响。查看当前位置所属范围的额度：

text
/bq status

额度按时间恢复，限制的是新生成的矿物方块，不是已经收进仓库的库存。不要因为暂时产出普通石头，就急着拆掉整套设备，先检查 资源额度说明。

6. 再决定你的第一条产线 ​

有了起步材料，再挑一件想省力的事：整理箱子、运输物品、加工材料，或者建设农场。科技模组可以按需要组合，玩法介绍里整理了 机器、能源与仓储的用途。

暂时卡住也没关系。带上任务条件、鱼竿等级或设备情况去群里聊聊，比只说“为什么不工作”更容易一起找到原因。
